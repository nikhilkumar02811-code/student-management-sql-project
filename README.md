🎓 Student Management System (SQL Project)

🚀 Project Highlights

* Designed relational database with **6 interconnected tables**
* Performed **data analysis using JOINs, Aggregations, and Subqueries**
* Calculated **course-wise GPA using CASE statements**
* Implemented **data integrity using constraints (UNIQUE, ALTER TABLE)**


📌 Overview

A SQL-based system to manage student, course, and enrollment data.
This project demonstrates **end-to-end database design + analysis using real-world academic scenarios**.

🛠️ Tech Stack

* SQL Server (SSMS)


🗂️ Project Structure

```text id="s4m3ha"
schema.sql   → Tables + data  
queries.sql  → Analysis queries  
README.md  
```


📊 Key Analysis

* 📈 Student count per department
* 🎯 Course-wise GPA calculation
* 📚 Student-course enrollment tracking
* 👨‍🏫 Instructor-course mapping
* ❌ Identification of courses with no enrollments



🧠 SQL Concepts Used

* Joins (INNER JOIN)
* Aggregations (COUNT, AVG, GROUP BY)
* Subqueries
* CASE statements
* Date filtering
* DML operations (UPDATE, DELETE)
* Constraints (UNIQUE, ALTER TABLE)

🚀 How to Run

1. Run `schema.sql`
2. Run `queries.sql`



📌 Conclusion

This project showcases strong SQL fundamentals including **database design, data analysis, and query optimization**, making it suitable for real-world data-driven applications.
